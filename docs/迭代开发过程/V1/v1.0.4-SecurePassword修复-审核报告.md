## 三、非阻断性发现

### 发现 1：PC_WEB 默认值缺少直接测试覆盖 🟡

**问题**：`domain-client-user.test.ts` 没有直接调用 `loginByContext("u","w")` 断言默认枚举值的用例。`transport.test.ts:88` 虽用了 `PC_WEB`/`PASSWORD`，但那是**显式传参**，而非测试默认值 `?? "PC_WEB"`。

**建议**：在 `domain-client-user.test.ts` 中增加：
```typescript
it("loginByContext defaults to PC_WEB / PASSWORD", async () => {
  // ...mock transport...
  const user = new DomainClientUser(transport, {});
  await user.loginByContext("admin", "x").catch(() => {});
  expect(executeSpy).toHaveBeenCalledWith(
    expect.objectContaining({
      variables: { input: expect.objectContaining({
        loginFrom: "PC_WEB",
        authType: "PASSWORD",
      })},
    })
  );
});
```

### 发现 2：EXPLICIT_MUTATIONS 包含 requestChallenge/registerSecure，但实际属 Query 根 🟢

**问题**：`EXPLICIT_MUTATIONS`（L482-483）将 `requestChallenge`/`registerSecure` 列为 mutation，但 schema 中它们属于 **Query 根**。直接 `execute` 调用使用 `type: "query"` 正确，但 `EXPLICIT_MUTATIONS` 的归类是冗余的（仅影响 ServiceProxy 前缀启发式，不影响直接 execute 调用）。

**结论**：不影响运行时行为，仅标记冗余，可清理。
