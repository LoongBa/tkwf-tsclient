## 四、Oracle 审核问题修复记录

| # | 问题 | 修复 |
|---|------|------|
| P1 | GroupBuilder 的 `or()` 与 `and()` 语义相同，静默陷阱 | 删除 `or()` 方法，纯 AND 模式 |
| P2 | 聚合查询 `first: 1` 参数未验证 schema | 移除 `first` 参数，聚合 resolver 无分页 |
| S1 | AggregateFieldsBuilder 字段全 public，无封装 | 字段改 `private`，新增只读 getter |
| S2 | toAggregateAsync 响应映射无 null 兜底 | `_sum/_avg/_min/_max` 加 `?? undefined` |
| S3 | clone() 注释 "append-only 不可变" 不准确 | 修正为"aggregate() 每次替换引用" |
| S4 | compileGraphQLAggregateMode 非空断言 | 替换为显式 guard + 抛出错误 |
| S5 | AggregateResponse._min/_max 类型缺 string | 改为 `Record<string, number \| string>` |
| S6 | 测试缺 avg/min/max 编译分支 | 新增 T55-T58 |
