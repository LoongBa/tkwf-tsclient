# v1.0.5 生成代码优化（基类化 + 泛型化 + 映射类型派生）— 审核报告

## 一、结论

**有条件通过**。方案 4 项变更全部落地并验证：SDK 173 tests 全部通过、DMP-Lite codegen 重生成成功、`tsc` 相对基线**零新增错误**。生成文件实际 3100 行（-28%），略低于方案预期 ~2900 行（-33%），差异经用户确认接受。

审核中发现 1 处本次引入但已修复的问题（生成器 import 模板 TS6196），以及范围外改动（消费端 Tkwf 门面迁移，用户已确认保留）。

## 二、变更核对

### 2.1 SDK：操作符工厂迁移 + QueryBuilderBase（`query-builder.ts`）

| 方案要求 | 实际 | 结论 |
|---------|------|------|
| `compileGraphQL` / `createOrderByProxy` abstract → 具体实现 | 已实现 | ✓ |
| 迁入 7 个操作符工厂（dummyAsc/dummyDesc/createOperators/createStringOps/createNumberOps/createDateOps/createBooleanOps） | 已迁入，作为命名导出 | ✓ |
| `createFieldsProxyFrom` 辅助（元数据表驱动） | 已实现 | ✓ |

工厂函数内容与原生成文件逐函数一致（LeafNode 构造参数、in/nin 单值语义保持），迁移无行为变化。

### 2.2 SDK：过滤类型分族（`query-builder-types.ts`）

| 类型 | 定位 | 结论 |
|------|------|------|
| `OperationFilterInput<T>` | 数值/日期族 12 操作符 | ✓ |
| `StringOperationFilterInput` | 字符串族（and/or + contains 族） | ✓ |
| `BooleanOperationFilterInput` | 仅 eq/neq | ✓ |
| `EnumOperationFilterInput<T>` | eq/neq/in/nin | ✓ |
| `PageInfo` / `Connection<TNode,TEdge>` / `Edge<TNode>` | HC 分页/连接泛型 | ✓ |
| `SelectFieldsOf<TFields>` / `OrderByFieldsOf<TFields>` | 映射类型派生 | ✓ |

与原生成文件接口结构比对一致（如数值族无 contains、String 族无 gt、Boolean 仅 eq/neq）。

### 2.3 SDK：导出（`index.ts`）

新增导出操作符工厂 8 个 + 类型 9 个，与 v1.0.4 导出风格一致。✓

### 2.4 生成器（DMP-Lite `gen-ts-client.ts`）

| 方案要求 | 实际 | 结论 |
|---------|------|------|
| FilterInput/Connection/Edge 输出类型别名 | 标量 3 族 → `OperationFilterInput<T>`；枚举族 → `EnumOperationFilterInput<string>`；String/Boolean → 引用 SDK 跳过本地；Connection/Edge → 泛型别名（含节点类型入队） | ✓ |
| SelectFields/OrderByFields 输出映射别名行 | `SelectFieldsOf<XxxFields>` / `OrderByFieldsOf<XxxFields>` | ✓ |
| createFieldsProxy 输出元数据表 | `createFieldsProxyFrom<XxxFields>({ field: "gqlType", ... })` | ✓ |
| 不再输出 compileGraphQL/createOrderByProxy/操作符工厂 | 已从模板删除 | ✓ |
| import 模板 | 精简为 SDK 所需符号；**修复：移除未使用的 SortNode/PageInfo（TS6196）** | ✓ |

### 2.5 生成产物（`ts-client.g.ts`）

- 行数：**4312 → 3100（-28%）**，预期 ~2900（-33%）。差距来源：Fields 接口平铺（方案 §3.6 明确保留）+ 枚举 FilterInput 别名数量多于预估。**用户已确认接受现状**。

## 四、范围外改动（用户已确认保留）

DMP-Lite 消费端在本次迭代中同步完成了 **HostClientProvider → Tkwf 全局门面迁移**（13 个应用文件：App.tsx、main.tsx、host-client-context.tsx、auth-provider.ts、session.ts 及 9 个页面），页面调用从 `host.GetUser().Use<X>()` 改为 `Tkwf.User.Use<X>()`。此部分不在本方案计划内，已征求用户意见并**确认保留**。

**行为变更提示**：session 持久化键由 `dmp_merchant_login` 变为 `default`（Tkwf 场景名即 storageKey）。部署后存量登录用户需重新登录一次。属于 Tkwf 门面既有语义，非本方案引入的缺陷。
